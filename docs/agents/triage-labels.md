# Triage 标签

技能用五个规范的 triage 角色发言；本文件把角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 技能中的角色 | 本 tracker 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 完全规格化，可交给离线的 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

若使用其它标签词，直接改右列即可。
